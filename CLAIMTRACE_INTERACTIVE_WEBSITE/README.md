CLAIMTRACE DATA PACKAGE

Purpose:
Data + research + qualitative framework + design system + website architecture + Google AI Studio master prompt.

The package uses the user's Kaggle states.csv as the reference dataset.

Data categories:
REAL_PUBLIC_DATA = sourced/curated public indicators.
SYNTHETIC_INTERACTIVE_DATA = invented records for prototyping and visualization.
KAGGLE_REFERENCE = original uploaded Kaggle dataset.

Do not present synthetic values as real claims.
Do not treat the 2010–2016 Kaggle state data as current.

Primary research sources:
IRDAI Handbook on Indian Insurance Statistics
IRDAI Health Department / FAQs
IRDAI Master Circular on Health Insurance Business 29-05-2024
National Health Accounts, Ministry of Health & Family Welfare
National Health Authority PM-JAY resources

Recommended next step:
Replace/add real datasets from official downloadable tables as they are acquired, while preserving source metadata and data-status labels.
